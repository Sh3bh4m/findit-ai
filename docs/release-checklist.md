# Public release checklist

- [x] Created a new, independent showcase directory; did not copy any ZIP's Git history.
- [x] Kept raw credentials, rules, database snapshots and unredacted videos outside the repository.
- [x] Used fabricated datasets and explicitly labeled reconstructed examples.
- [x] Differentiated implemented components, staged features and Laya experiments.
- [ ] Confirm publisher's GitHub identity and repository visibility.
- [ ] Confirm employer/client intellectual-property and naming permission for any proprietary material.
- [ ] Decide on an appropriate open-source license (if source reuse is intended).
- [ ] Review complete staged contents and full commit history for secrets and client references.
- [ ] Confirm GitHub connector/CLI permissions to create and push repositories.
- [ ] Publish and verify public URL, README, tests and visible files.

The **actual production code and source archives should not be added** without a separate ownership, privacy and security review.
